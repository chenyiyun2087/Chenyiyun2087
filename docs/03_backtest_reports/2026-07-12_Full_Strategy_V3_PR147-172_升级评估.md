# Full Strategy V3：PR #147–#172 升级与生产发布评估

## 一、结论

评估基线为远端 `origin/main` 提交 `36a644588750795aea55e8cb678fdfc30413cf91`，范围为 2026-07-10 至 2026-07-12 合并的 PR #147–#172。

**总判断：研究与验证基础设施显著升级，但尚未证明策略经济价值升级；当前为 `NO-GO / RESEARCH_ONLY / NO_SCALE`。**

- 已升级：可执行标签、PIT 组合约束、状态化退出、成本压力、账户级 OOS、独立 oracle、证据 fail-closed、季度窗口、随机/反转基线、来源快照和证据哈希。
- 未证明：最终提交上没有来源齐全、逐季度可复现、相对冻结 Champion 有净增益的正式证据包。

- 正式验证：非 `precheck-only` 的 V3 runner 在数据库快照阶段因缺少只读数据库凭据终止，未生成 manifest。
- 生产决策：维持 `production_governed_vol_position`，冻结 v1.2b Champion 仅作比较基准，不新增风险敞口。

这批 PR 的主要价值是让偏乐观结果更难误通过，而不是已经证明产生更高的可执行收益。连续多个“final/close”PR 后仍反复修正同一证据与经济契约，说明单 PR 自报测试通过不能代替端到端验收。

## 二、评分口径

五维评分采用 `0/1/2`：`0` 无直接贡献或未验证，`1` 有局部贡献，`2` 有明确实现贡献。维度依次为收益、风险、PIT、研究—生产一致性、证据完整性。“有效”不等于允许生产晋级；“部分有效”表示方向正确但经济证据未闭环；“仅工程有效”表示提高可信度但没有证明 alpha 增益。

## 四、验证结果与硬阻塞

### GitHub 与本地复现

提交 `36a64458` 的重复 push/PR workflow 结果一致：`production-core`、`strict-ledger`、fixtures 失败；integration-test 和 secret-scan 成功。GitHub 的 PR18 组包含 parquet 引擎缺失，但不是唯一原因：本地已有 `pyarrow` 时仍复现 8 个语义失败。

| 套件 | 结果 | 关键失败 |
|---|---|---|
| 生产核心等价套件 | 133 passed / 8 failed | evidence 返回契约、PIT mutation、ledger/NAV 守恒、季度范围 |
| strict-ledger fixtures | 67 passed / 2 failed | 涨停拒单误报；不可交易订单缺 reject reason |
| PR 专项集合 | collection failed | PR11、PR23、PR24、PR25 在本机 Python 3.9 有语法错误；CI 3.11 仍有独立失败 |
| 正式 V3 runner | 未进入实验 | 数据库无只读凭据，未生成 manifest |

生产发布前必须全部完成：

1. 锁定 Python 3.11 与 parquet 依赖，required checks 连续两次全绿，并修复真实语义失败。
2. 用只读数据库完成非 precheck V3 runner，覆盖 10 个季度、8 组实验、RND_TOP30、RND_FULL、REV_A7 和逐实验账户账本。
3. manifest 为 `REPRODUCIBLE`；verification hash、公司行为、证券生命周期、交易日历和来源覆盖全部通过。
4. 同一 T+1、成本、滑点和账户口径下，候选相对当前生产及冻结 Champion 有净增益，季度 OOS 与压力成本不反转。
5. strict ledger 为 `VERIFIED`，拒单、成交、现金、持仓、NAV 和回放一致；PR26B 独立复核完成并审批。

## 六、升级结论

1. **研究能力有效升级**：标签、PIT、账户经济、成本、风险、退出和 OOS 框架更接近可信标准。
2. **经济效果无充分证据**：不能声称收益、Sharpe、回撤或容量已经改善；多数 PR 修复的是会改变历史结果的测量错误。
3. **执行安全方向正确但未验收**：fail-closed、硬约束、来源快照和 strict ledger 必要，但红灯与拒单回归使其尚不具备发布资格。
4. **当前路由保持不变**：不晋级 V3，不开启研究 shadow 配置，不新增风险资金。
5. **下次评审触发点**：最终提交取得完整绿色 CI、可复现正式证据、独立复核和 20 个真实影子交易日，而不是再合并一个名为“final”的 PR。
