# 全策略统一赛马生产化实施摘要

## 结论

截至 2026-07-12，本轮完成生产化门禁与统一赛马代码实施，但没有只读数据库凭据，因此
没有运行正式全历史/10季度经济实验，也没有策略获得生产晋级。结论为
`IMPLEMENTED_BUT_BLOCKED / NO-GO / NO_SCALE`。

## 已完成

- 移除扫描发现的全部 Python/JSON 数据库明文口令，统一显式读取
  `CHENYIYUN_DB_URL`，增加 AST/JSON 凭据扫描与 gitleaks 规则。
- CI 固定 Python 3.11，三条发布工作流统一使用 `requirements-ci.lock.txt`，并锁定
  `pyarrow==20.0.0`。
- 保留 Evidence V4 10季度契约，修复旧测试、NAV 守恒诊断、PIT 稀疏因子处理和
  strict-ledger 拒单状态/原因。
- 增加只读统一赛马入口、硬门槛配置、候选身份校验、季度指标、排名、输入哈希和不可变
  manifest。
- Canary 门禁统一为 20日 disabled + 60日 enabled + 30回合；完成前不得开启新买单。
