# Alpha v3.1 证明层升级记录

## 来源

本轮升级依据 Alpha v3.0 独立评估结论实施。评估确认工程治理已接近机构标准，
但 Alpha 证明、统计稳健性、执行真实性和容量证据不足；最高价值升级点是先回答
“收益为什么产生”，而不是继续提高回测收益。

## 已实现

- 在统一 `alpha_v3` 档案中加入 `alpha_v3_1_proof_v1` 证明合同。
- 基准集合扩展为沪深300、中证500和中证1000，三条序列必须全部完整；输出
  年化收益、年化超额、信息比率、Beta 和年化 Alpha。
- 新增日频多因子证明层，要求市场、规模、波动率、流动性、行业、动量、价值和
  市场状态全部存在、至少 252 个对齐交易日、覆盖率不低于 95%、回归矩阵满秩。
- 归因以对齐日收益的算术和为闭合口径，因子贡献加
  `stock_selection_alpha` 必须在配置容差内精确闭合；同时独立披露复合收益。
- 统一验证包新增 `benchmark_excess_report.json` 和
  `alpha_proof_report.json`，证据清单升级为 v3.1。
- 旧版、无 schema 或缺少日频因子证据的归因 JSON 不得绕过 v3.1 门禁。
- 复用现有正式 OOS 模块中的 DSR、CPCV-PBO、Block Bootstrap 和多因子回归，
  未创建另一套不兼容的统计口径。

## 保持不变

- Meta Allocator 已在验证路径中让市场状态控制总仓位，并保留核心、进攻、均衡、
  防御四角色；本轮不修改生产默认路由。
- 缺少正式 PIT、三基准净值、因子收益面板、横截面因子面板、正式 Walk-forward、
  真实成交和 Shadow 时继续 `BLOCKED / NO_SCALE`。
- 研究证明层即使 PASS 也不授权资金，不启用 Canary 或券商 API。

## 测试

新增合成夹具验证：

- 三基准必须全部存在；
- 超额、IR、Beta 和 Alpha 可计算；
- 因子回归必须满秩；
- 归因在容差内闭合；
- 证明层永不直接授权资金。

相关 v3.1、正式 OOS、市场状态、Meta Allocator 和准入回归共 117 项通过。
Python 3.11 完整套件为 1503 passed、15 skipped、1 failed；唯一失败仍是要求
真实 MySQL 的 `TestL10QuarterlySmoke`，当前连接对象为 Mock，无法完成服务器
版本握手。该环境阻塞未被改成跳过。

## 仍需外部证据

1. 2018+ 正式 PIT 股票生命周期、财务、公司行动、ST 和停牌快照。
2. 同一冻结日历上的沪深300、中证500、中证1000净值。
3. 八项日频因子收益和 5/10/20 日横截面因子面板。
4. 正式 3 年训练/半年测试滚动样本外结果。
5. 涨跌停、未成交冻结和真实成交回报。
6. 20 日技术 Shadow、60 日经济 Shadow 和 30 个闭环交易。
