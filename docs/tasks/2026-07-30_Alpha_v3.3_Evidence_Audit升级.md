# Alpha v3.3 Evidence Simulation & Audit 升级记录

## 来源与边界

本轮依据 v3.2 独立投委会复评实施。复评未发现 P0，但指出因子来源版本、年度
完整度、最差年度 Alpha、IC 到组合收益的联动和容量证据仍是 P1。升级只增加
研究证据与失败关闭，不修改生产路由、Canary、券商 API 或资金权限。

## 已实现

- 默认档案升级为 `alpha_v3_3`，证据合同为 `alpha_v3_3_evidence_v1`；
  `alpha_v3` 与 `alpha_v3_2` 仅作为兼容别名。
- 新增 `factor_lineage_report.json`。每个因子必须声明数据版本、冻结源文件路径
  和 SHA256；运行时重新计算真实文件 SHA，并校验因子收益及 IC 面板中的版本和
  SHA 列，防止“时间正确但使用后来修订数据”。
- Residual Audit 改为双阈值：未解释方差 5%–10% 进入人工审查，超过 10% 硬
  阻断；无论残差比例如何，`alpha_tstat < 2` 均阻断。
- 年度稳定性新增每年至少 9 个覆盖月份和最差年度年化 Alpha 高于 -10%；
  不完整年度只作诊断，不参与 PASS。
- 因子有效性扩展至 5/10/20/60 日，新增
  `factor_effectiveness_report.json`，披露 Pearson IC、Rank IC、多空收益、
  组合加权远期收益、组合因子暴露与远期收益相关性及衰减曲线。
- 新增 `capacity_curve_report.json`，按 5万、10万、50万、100万、500万元
  计算 ADV 参与率与模型滑点；缺少 `adv20_cny` 时失败关闭，模型结果不能替代
  真实成交。
- 新增 `regime_conditional_attribution_report.json`，要求
  `market_regime_state`，按 FREEZE、RISK_OFF、NEUTRAL、RISK_ON、
  BROAD_RISK_ON 分组披露收益和波动；缺少状态证据时阻断。

## 实际结果

当前正式因子来源清单、因子/IC 面板、ADV 和市场状态标签均不存在，因此新增
报告准确保持 `BLOCKED`。历史指标仍为年化 20.37%、最大回撤 -25.52%、
Sharpe 0.82；统一结论仍为 `BLOCKED / NO_SCALE`，允许新增资金 0 元。

正式输出位于 `exports/alpha_v3_validation/20260730_alpha_v3_3/`。相同输入重复
执行得到一致的确定性证据 SHA：
`fb8d3ae0d4047f088e1317aa592f04cce1cc3a20f881976570ba8ecea259666a`。

Python 3.11 相关回归为 43 passed；非集成全量为 1509 passed、11 skipped、
7 deselected。真实 MySQL 季度烟测仍需外部数据库环境，不改成跳过。
