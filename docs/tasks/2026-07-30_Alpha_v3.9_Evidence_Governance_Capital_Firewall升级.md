# Alpha v3.9 Evidence Governance & Capital Firewall 升级记录

## 目标

根据 v3.8 第六轮独立复评，把“证据存在”升级为“证据强度可比较”，并在
Capital Gate Simulator 与实际资金状态之间加入机器可执行的资金防火墙。
本轮不新增 Alpha、不补造行情/PIT/Shadow 数据、不修改生产路由，也不启用
Canary 或真实报单。

## 实现

- 默认档案升级为 `alpha_v3_9 / alpha_v3_9_evidence_v1`。
- 新增 `evidence_strength_report.json`，将证据分为 E0（缺失）、E1（代码/
  重放）、E2（模拟/纸面）、E3（release-scoped 历史真实数据）、E4
  （release-scoped Shadow/真实交易）。不同等级不可相互替代。
- Evidence Contract Matrix v2 为每个 BLOCK 增加 Research、Trading、Capital
  三层 `impact_scope`。
- 新增 `capital_firewall_report.json`。Alpha 必须达到 E3、真实 Shadow 必须
  达到 E4，并同时通过投资、交易和 release 绑定人工审批要求；否则有效允许资金
  固定为 0。模拟器和防火墙顶部均输出
  `SIMULATION ONLY | NO CAPITAL AUTHORITY | NO BROKER ACTION`。
- 新增 `evidence_promotion_workflow_report.json`，显式表达
  `BLOCKED → EVIDENCE_ADDED → VALIDATION → PROMOTION_REVIEW → PASS`，禁止
  自动晋级。
- 新增 `alpha_claim_registry_report.json`。当前只允许声明
  `RESEARCH_STRATEGY`，禁止把未闭合证据描述为 `REGRESSION_ALPHA`、
  `STOCK_SELECTION_ALPHA`、`TRADABLE_ALPHA`、`LIVE_ALPHA` 或
  `CAPITAL_READY`。
- 新增组合会计闭合报告，要求每日 NAV 变化与持仓盈亏、现金变化、交易成本和
  手续费闭合；缺少正式字段时失败关闭。
- 新增 Failure Coverage Matrix，按数据泄漏、执行、会计、市场微观结构、
  公司行动和幸存者偏差披露覆盖。当前微观结构与公司行动仍为 `PARTIAL`，
  不以 20/20 注入数量掩盖类别缺口。
