# Alpha v4.1 Evidence Acquisition Pipeline 升级记录

## 结论

v4.1 已把验证链从“治理报告继续扩张”切换到真实证据获取：新增有界数据发现、
资格审查、合格资产冻结、证据适配和刷新队列。流水线不会因为文件名或旧报告
存在就认定证据有效，只冻结满足 release、策略、时点和数据质量合同的输入。

本轮没有取得可用于 Alpha 证明的 E3/E4 证据。正式结论仍为
`BLOCKED / NO_SCALE / 0 元`，没有启用 Canary、真实报单或券商 API。

## 实际发现

- 基准候选：19 个，均为汇总或比较表，缺少三指数逐日
  `benchmark/trade_date/nav/available_at` 合同。
- 因子候选：5 个 `bs_training_dataset*.parquet`；仅 137–138 个交易日，
  缺少八因子、`signal_time` 和逐因子 `available_at`，不能作为可信 IC/归因输入。
- PIT 候选：12 个；现有 forward-only 记录不是当前 release/策略的正式 PIT，
  `formal_pit_eligible=false`，停牌来源也不完整。
- 执行候选：1 个历史交易文件；仅完成发现，不能替代 release-scoped E3
  真实执行或 E4 Shadow。
- Shadow 候选：0 个。
- 本地 MySQL 只读连通性检查受凭证限制，返回 1045；未把数据库内容或旧报告
  推断为可用证据。

## 资格与失败关闭

刷新队列按以下顺序保持 OPEN：

1. 获取沪深300、中证500、中证1000逐日 NAV，并提供带时区的 `available_at`。
2. 生产与信号时点一致的 release-scoped 因子收益及 IC 面板。
3. 为当前 release/策略运行正式 PIT 捕获并补齐停牌等来源。
4. 累积真实 Shadow 交易日和闭环交易。

只有通过资格审查的资产才会复制到 `evidence_snapshots/` 并生成适配路径。本轮
四类正式证据均为 `BLOCKED`，所以快照资产为空，适配器全部阻断。
