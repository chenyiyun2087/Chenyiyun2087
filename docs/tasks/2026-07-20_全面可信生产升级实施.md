- 生产状态统一为 `READY / REVIEW_ONLY / FREEZE_NEW_BUYS / HALT_NEW_ORDERS / BLOCKED`，未知订单数、候选数、NAV 或数据身份一律阻断。
- 当前批准仓位上限固定为 50% NAV，系统绝对上限保留85%；账户风控支持当前持仓、未成交订单和新订单的完整投影。

- Release、订单、Fill、账本和证据统一使用不可变身份；人工 Fill 保存离线券商标识、源文件 SHA、导入时间并按全部成交累计 VWAP、费用和名义金额。
- 新增严格账本与独立账本统一输入包验收工具，固定生成双账本、订单、持仓、NAV 和首差异报告。
- 新增开盘执行概率代理、Base/Conservative/Stress 全成本模型、20笔连续偏离冻结门禁。
- 正式研究门槛更新为 DSR 95%、PBO 20%、正收益窗口60%、随机和反向基线胜率70%；新增 CPCV、White Reality Check 和实验查看审计。
- 新增六因子不可变注册表、L0—L6消融语义、Ledoit-Wolf风险模型、市场状态缓冲控制和人工资本阶梯门禁。
- 不连接任何券商 API；新增仅解析人工导出文件的 `BrokerStatementAdapter`，对账不一致即 `HALT_NEW_ORDERS`。
- Evidence Store 支持外置卷第二副本、引用记录、审计日志、容量检查和需审批的孤儿清理。
- Release CI 强制接收真实 PIT Manifest、双账本输入包、只读数据库凭据和两个证据卷。
