# Alpha v3.8 Evidence-to-Decision Control Plane 升级记录

## 目标

根据 v3.7 第五轮独立复评，把“为什么不能投”的证据审计升级为可机器执行的
“何时才具备人工复核资格”。本轮不新增 Alpha、不补造行情/PIT/Shadow 数据、
不修改生产路由，也不启用 Canary 或真实报单。

## 实现

- 默认档案升级为 `alpha_v3_8 / alpha_v3_8_evidence_v1`。
- 新增事件正确性覆盖：在既有 100 日确定性分层抽样之外，加入每年 10 个
  anchor 日，以及 ST 变更、停复牌、涨跌停、退市和普通样本的固定配额。
- 新增组合状态审计，检查现金、总权重、净/总暴露、换手和行业暴露；缺字段
  失败关闭。
- 新增 Evidence Contract Coverage Matrix。每个 PASS 必须包含 evidence SHA、
  timestamp 和 release；每个 BLOCK 必须包含稳定 `gap_id`。
- 新增 Evidence Issue Tracker。每个阻断项包含 owner、fix_action、
  verification、fix_commit、verification_run 和 resolved_at。
- 新增 Capital Gate Simulator。它只模拟未来证据全部通过后是否具备人工复核
  资格，固定 `capital_authority=false`，不能开启 Canary、券商路由或资金。
- 将易误读的 release readiness 改为 `Engineering Readiness Score`，顶部固定
  `NOT AN INVESTMENT READINESS SCORE`；同时独立输出 Engineering、Evidence、
  Investment 三种不可替代的分数。
- Failure Injection 升级为 v5，加入集合竞价价格前视、订单排队优先级、数据
  供应商语义变化和数值精度跨阈值漂移；20 项注入全部被检测。
- 新增策略健康诊断，披露可计算的收益/回撤/波动信息，对缺少换手和风格暴露
  明确失败关闭。

## 验证

- 相关回归：`52 passed`。
- Python 3.11 非集成完整套件：
  `1518 passed, 11 skipped, 7 deselected`。
- reference/replay 的 metadata、NAV、交易、归因和风险差异均为 0。
- Failure Injection v5：`20/20` 检出。
- replay 重复运行确定性 SHA：
  `07706da0c33e01482322a0595a7d4a54a7d32565528e3d665d39a9d21ecc7a51`。

## 实际结论

Engineering Readiness Score 为 85/100，Evidence Coverage 为 21/100，
Investment Readiness 为 0/100。三种分数不可相互替代。

历史指标保持不变：2023-11-30 至 2026-06-17 共 615 个交易日，累计收益
57.23%、年化 20.37%、最大回撤 -25.52%、Sharpe 0.82。

当前事件分类、组合状态字段、正式三基准、PIT、因子/IC 面板、独立选择归因、
真实成交和 release-scoped Shadow 仍缺失。最终保持
`BLOCKED / NO_SCALE`，允许新增资金 0 元。
