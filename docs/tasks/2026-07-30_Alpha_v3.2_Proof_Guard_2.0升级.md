# Alpha v3.2 Proof Guard 2.0 升级记录

## 目标

本轮落实 v3.1 复评的四项 P1 改进：因子时间可用性、残差审计、年度 Alpha
稳定性和基准降级保护。升级只增强研究证据可信度，不修改生产策略、券商路由、
风险上限或资金阶梯。

## 已实现

- 默认验证档案升级为 `alpha_v3_2`（`alpha_v3` 仅保留兼容别名），证据合同为
  `alpha_v3_2_evidence_v1`，新增
  `alpha_proof_guard_report.json` 并接入研究晋级硬门禁。
- 因子收益和横截面 IC 宽表必须提供带 Asia/Shanghai 时区的 `signal_time` 与
  八个 `<factor>_available_at`；缺失、无时区、时区不一致或
  `available_at > signal_time` 均失败关闭。
- OLS 截距改称 `regression_alpha`。报告独立披露残差均值、标准差、t 值、
  累计未解释收益和未解释方差比例；后者超过 5% 即阻断。
- `stock_selection_alpha` 只接受
  `alpha_v3_2_selection_attribution_v1` 独立证据，且必须匹配 release、策略、
  样本范围和 64 位输入快照 SHA。v3.1 归因文件不得绕过门禁。
- 按 2023–2026 分年验证回归 Alpha。单年至少 126 个交易日、至少三个有效年度、
  正 Alpha 年份比例至少 60%，任一年正 Alpha 贡献不得超过 60%。
- 沪深300、中证500、中证1000逐条检查重复日期、非正 NAV、带时区可得时间、
  末日一致性、252 日下限和 95% 覆盖率；任何一条不完整均禁止降级替换。

## 资金与生产边界

Proof Guard、研究历史表现和外部评估均不能直接授权资金。缺少正式三基准、因子
面板、PIT、Walk-forward、真实成交和 Shadow 证据时，统一输出继续为
`BLOCKED / NO_SCALE`，允许新增资金 0 元；Canary 和券商 API 保持关闭。

## 验证

合成测试覆盖时间等号边界、未来时间、无时区与混合时区、残差 5% 门槛、多年度
稳定性、独立选股归因身份与 SHA、基准 95% 边界及非法 NAV。正式证据包仍只记录
实际可得信息，不填充或推断缺失数据。

正式输出位于 `exports/alpha_v3_validation/20260730_alpha_v3_2/`。相同输入重复
执行得到一致的确定性证据 SHA：
`a082a12501cc5a425b100d56faa406f9c9ee7cd26ffc14cde046b469e3e3afd9`。

Python 3.11 非集成全量测试为 1507 passed、11 skipped、7 deselected。包含集成
测试的全量运行有 1509 passed、15 skipped、1 failed；唯一失败仍是明确要求真实
MySQL 的 `TestL10QuarterlySmoke`，当前 Mock 连接无法完成服务器版本握手，未被
改成跳过或伪报通过。
