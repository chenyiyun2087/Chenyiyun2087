# Alpha v4.0 Capital Readiness Simulation Framework 升级记录

## 目标

根据 v3.9 第五轮独立复评，在不补造三基准、PIT、因子、Shadow 或真实成交的
前提下，建立可审计的资本准入模拟。所有新组件只解释证据和人工复核资格，不
启用 Canary、券商 API、真实报单或资金。

## 实现

- 默认档案升级为 `alpha_v4_0 / alpha_v4_0_evidence_v1`。
- 新增 `evidence_expiration_report.json`：E1/E2 证据有效 30 日、E3 有效
  180 日、E4 有效 30 日；缺失、无时区、解析失败或过期均失败关闭。
- 新增 `capital_tier_engine_report.json`：模拟 T0 Research、T1 Paper、
  T2 5万元 Canary、T3 50万元受控规模和 T4 扩展规模。T2 仍要求 E3 Alpha、
  E4 Shadow、release 绑定审批和既有更严格的真实交易门槛。
- 新增 `claim_lifecycle_report.json`：允许证据状态自动推导
  `RESEARCH_STRATEGY → EVIDENCED_STRATEGY → SHADOW_VALIDATED_STRATEGY
  → TRADABLE_STRATEGY`，但 `CAPITAL_APPROVED_STRATEGY` 永远要求独立人工
  授权，禁止自动资本晋级。
- 新增 `strategy_health_monitor_report.json`：监控收益衰减代理、波动切换、
  当前回撤、换手异常、风格漂移和逐日 regression alpha。缺正式字段时明确
  `BLOCKED`，不把组合收益称为 Alpha。
- 新增 `independent_reviewer_simulation_report.json`：汇总支持证据、稳定
  gap、过期项、最高声明、模拟资金层级、健康状态和禁止动作，只输出
  `NO_GO` 或“可提交独立人工复核”，没有资本权限。
