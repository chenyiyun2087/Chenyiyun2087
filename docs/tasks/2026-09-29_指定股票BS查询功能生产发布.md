# 指定股票 B/S 查询功能生产发布

## 冻结复核与决定

复核了 2026-09-03 和 2026-09-04 的系统稳定性审计记录。审计记录确认队列跨日处理、模型指针保护、运行时预检和 worker 连接超时等问题已修复并发布；冻结继续生效的目的，是等待稳定性窗口结束后由操作人复核并决定是否恢复普通发布。

2026-09-29，操作人明确要求解除生产冻结并发布本功能。发布前 Web console 与 task worker 均处于运行状态，`scripts/ops/check_web_console.sh` 健康检查通过。依据上述复核及操作人决定，冻结记录状态从 `PAUSED` 改为 `RESUMED`，恢复冻结控制覆盖的普通发布通道；本次发布不涉及模型、策略指针或资本配置切换。

## 发布内容

- 持仓页新增股票代码查询区：优先查当天 `config_1` 本地 B/S 结果；对未命中的代码复用 Sina OCR 截图与检测流水线；按代码输出结果并汇总 B/S 信号。
- 新增 `POST /api/sina/bs-lookup` 接口，单次最多 100 个代码。
- 发布脚本显式共享由符号链接提供的持久化输出目录，避免切换版本时遗漏数据库外的运行产物。
- 发布版本：`chenyiyun-prod-20260929-bs-lookup`。发布 commit SHA 以正式运行清单为准。
