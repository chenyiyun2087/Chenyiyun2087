# Alpha v3.5 Replay Diff & Audit Intelligence 升级记录

## 目标

根据 v3.4 第三轮独立复评，把研究重放从“发现 SHA 不一致”升级为“定位具体
漂移位置”。本轮不增加新 Alpha、不补造外部数据、不修改生产路由，也不启用
Canary 或真实报单。

## 实现

- 默认档案升级为 `alpha_v3_5 / alpha_v3_5_evidence_v1`。
- 新增 `environment_manifest.json`，冻结 Python、完整包版本、操作系统、架构和
  时区，并生成 `environment_lock_hash`；该哈希同时进入 release replay 与因子
  pipeline 合同。
- 因子计算血缘增加结构化语义定义及其 SHA。最终 pipeline hash 绑定公式版本、
  语义定义、代码、配置、输入和环境。
- 新增 `replay_snapshot_report.json` 与 `replay_diff_report.json`，逐层比较
  metadata、NAV、交易、归因和风险；差异明细最多保留 100 行，同时披露完整差异
  计数和截断标记。
- 故障注入升级为 v2，在原四项基础上增加输入快照篡改、公司行动前视、T 日成交
  和组合权重前视。
- 执行压力指标明确改为 `Execution Robustness Stress Index`，并以
  `SIMULATION / PAPER / LIVE` 三层隔离；模拟结果永远不能替代 Shadow 或真实成交。
- 新增证据依赖图，机器可读地表达
  `Data → Alpha → Trading → Capital` 的阻断传播关系。

  `165e47d3977aac09e5e504b7354a515e6ef1c90e814e4a46c2ae1317db5c6525`。

## 实际结论

历史指标没有改变：2023-11-30 至 2026-06-17 共 615 个交易日，累计收益
57.23%、年化 20.37%、最大回撤 -25.52%、Sharpe 0.82。

正式因子计算 manifest、三基准、PIT、因子/IC 面板、独立选择归因和真实 Shadow
仍缺失。历史交易明细没有 `limit_status` 和 `fill_status`，因此
`Execution Robustness Stress Index` 继续 `BLOCKED`。最终结论保持
`BLOCKED / NO_SCALE`，允许新增资金 0 元。
