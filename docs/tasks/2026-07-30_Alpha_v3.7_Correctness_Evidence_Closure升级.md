# Alpha v3.7 Research Correctness Evidence Closure 升级记录

## 目标

根据 v3.6 第四轮独立复评，把研究正确性审计从“列出阻断原因”升级为可执行的
证据修复清单，并加强合成正确性回归、环境指纹和证据依赖解释。本轮不新增
Alpha、不补造外部数据、不改变生产路由，也不启用 Canary 或真实报单。

## 实现

- 默认档案升级为 `alpha_v3_7 / alpha_v3_7_evidence_v1`。
- 正确性抽样改为固定种子的确定性分层抽样，覆盖下跌尾部、上涨尾部、极端波动、
  月度边界和随机对照，共 100 个交易日。
- 新增 `research_gap_report.json`，把缺失字段和合同映射为 P1 缺口、来源节点及
  可执行修复动作。
- 证据依赖图升级为 v2，把交易生命周期字段和研究—生产信号合同等缺口节点显式
  连接至 Trading 与 Capital 阻断链。
- 新增 `correctness_synthetic_suite_report.json`，以九个确定性场景覆盖基线、
  ST 显式分类、财报延迟、同日成交、停牌、退市、涨跌停和非法成交价。
- Failure Injection 升级为 v4，新增未来复权因子、股票池幸存者偏差、财报修订
  污染和同时间戳排序不确定性；16 项注入全部被检测。
- 环境指纹补充 CPU/指令集可见性、kernel、文件系统编码、容器镜像 digest 字段
  和依赖锁文件 SHA；宿主未暴露的项目以 warning 披露，不伪造值。
- 新增 `release_readiness_score_report.json`。该分数只衡量工程证据系统，明确
  `not_investment_score=true`、`capital_authority=false`，不能授权资金。

## 实际结论

工程发布就绪分为 85/100，唯一未得分的组件是仍处于 `BLOCKED` 的真实研究
正确性证据。历史交易缺少 `signal_time`、`execute_time`、`fill_status`、
`limit_status`、ST/停牌/退市和财务可用时间字段，也缺研究—生产信号合同。

历史指标保持不变：2023-11-30 至 2026-06-17 共 615 个交易日，累计收益
57.23%、年化 20.37%、最大回撤 -25.52%、Sharpe 0.82。正式三基准、PIT、
因子/IC 面板、独立选择归因和真实 Shadow 仍缺失。最终保持
`BLOCKED / NO_SCALE`，允许新增资金 0 元。
