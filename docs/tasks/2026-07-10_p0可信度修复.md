# P0 可信度修复

## 目标

在不改变当前生产选股、权重和仓位路径的前提下，修复策略身份、发布状态、配置字段和绩效窗口的可信度问题。

## 变更

- `config/strategy_release_registry.yaml` 成为策略生命周期和发布身份的单一真源；数据库注册表仅保留部署历史与审计用途。
- `production_governed_vol_position_v1_2b_dynamic_score` 冻结为 Champion 基准，但维持 `FAILED_REVALIDATION / BLOCKED / NO_SCALE`，不切换生产路由。
- 生产配置使用严格 Pydantic Schema，未知或拼写错误字段直接失败；研究功能必须明确标注状态。
- 生产绩效报告默认禁止替代策略；显式诊断替代必须标注为非生产报告。
- 报告、候选和订单输出共享 provenance 契约；历史缺失快照明确记录为 blocked，不伪装为完整证据。
- 1y/3y 等窗口同时报告请求范围、实际范围、交易日和覆盖率，覆盖率低于 90% 时标记不足。

## 生产影响

当前 `production_governed_vol_position` 路由和 `baseline_full_liquidity_detail_vol_position` 选股引擎不变。本阶段只收紧配置与报告门禁。

## 回滚

回滚本 PR 即可恢复旧解析方式；注册表未执行数据库迁移，也未改写历史研究产物。
