# Alpha v3.6 Research Correctness Audit 升级记录

## 目标

根据 v3.5 第四轮独立复评，把“可重复”与“正确”分开验收。本轮不新增
Alpha、不补造外部数据、不改变生产路由，也不启用 Canary 或真实报单。

## 实现

- 默认档案升级为 `alpha_v3_6 / alpha_v3_6_evidence_v1`。
- 环境合同增加随机种子、NumPy 种子、Python hash seed、线程数、BLAS、
  locale 和有效线程环境，统一进入环境锁。
- Replay diff 增加 `CRITICAL / WARNING` 严重等级和动作，但精确门禁仍是
  `ANY_DIFFERENCE_BLOCKS`；100 行只限制展示，不限制完整计数。
- Failure Injection v3 新增财务公告日污染、停牌成交、涨跌停队列虚假成交和
  退市幸存者偏差，12 项注入全部被检测。
- 新增 `research_correctness_audit_report.json`：用固定种子抽取 100 个交易日，
  检查 NAV、信号/执行时间、成交价、停牌/退市/涨跌停成交、财务可用时间，
  并要求研究与生产信号 SHA 一致。
- 当前历史交易文件缺少上述正式审计字段，且未提供研究—生产信号合同，因此
  正确性审计按设计 `BLOCKED`，没有用 Replay PASS 推导正确性 PASS。

## 验证

- v3.6 专项测试：`22 passed`。
- 相关回归：`48 passed`。
- Python 3.11 非集成完整套件：
  `1514 passed, 11 skipped, 7 deselected`。
- reference/replay 的 metadata、NAV、交易、归因和风险差异均为 0。
- replay 包重复执行确定性 SHA：
  `2197483bced5fefe3db7a8a26f8f30a3da14ee2a640c4157e40f4ef978b67576`。

## 实际结论

历史指标保持不变：2023-11-30 至 2026-06-17 共 615 个交易日，累计收益
57.23%、年化 20.37%、最大回撤 -25.52%、Sharpe 0.82。

正式三基准、PIT、因子/IC 面板、独立选择归因、正确性交易字段、研究—生产
信号合同和真实 Shadow 仍缺失。最终结论保持 `BLOCKED / NO_SCALE`，允许新增
资金 0 元。
