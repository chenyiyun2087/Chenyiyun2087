# 可信生产闭环升级

## 目标与边界

- 保留 `production_governed_vol_position` 及 50 万元固定本金，不扩资。
- 仅生成订单草案并由人工下单；不接入 QMT，不允许自动提交委托。
- 数据、身份、风险、双账本、人工成交或账户对账任一失败时进入 `FREEZE_NEW_BUYS`。
- 代码完成不代表策略晋级；正式 Walk-forward 和 20+60 个真实影子交易日仍是外部时间门槛。

## 本次实现

- 新增不可变 `ReleaseIdentity`、PIT `SnapshotManifest` 和本地 SHA256 内容寻址证据库。
- 新增独立订单/现金/持仓/NAV 回放与 0.01 元现金、1bp NAV 双账本核对。
- 风险统一为 NAV 分母：单股 18%、行业 35%、主题 55%，缺数据一律阻断。
- 新增 09:25 预检、T+1 开盘、09:31–09:35 VWAP 回退和保留现金执行模型。
- 人工成交改为不可变 `fill_id`、订单与发布身份匹配后才能导入；账户核对改为只读。
- Walk-forward 固定为 12/3/3 月、3 月滚动、purge 10 日、embargo 5 日；赛马要求双账本、随机/反向基线和因子消融。
- LLM/Claude 分仅允许 Shadow、解释、异常标注和重大事件否决，不允许生产排序。
- 增加快速、生产核心、夜间和发布证据四级 CI；Branch Protection 需两个连续全绿 run 后单独启用。

## 当前结论

状态保持 `BLOCKED / NO_SCALE`。仓库实现了硬门禁和证据接口，但尚未取得真实 PIT 全量快照、正式赛马、双账本全历史验证及 80 个真实影子交易日证据。
