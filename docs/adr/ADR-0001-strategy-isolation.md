# ADR-0001: sina 与 chenyiyun 策略体系必须保持决策逻辑隔离

## 状态
已接受（Accepted）

## 日期
2026-06-21

## 背景
项目包含两套独立的策略体系：
- **sina**：以 Sina 财经 B/S 检测为起点，经 ScoreRank 三线评分、M2-M8 评估链、M7 调仓。
- **chenyiyun**：迁移自 JoinQuant 的多因子策略，使用本地 Tushare 数据仓库。

两套体系共享 MySQL、交易日历、Web 控制台，但信号生成和调仓逻辑完全不同。

## 决定
1. sina 和 chenyiyun 的信号生成、排名、调仓参数、回测结论**完全独立**。
2. 共享基础设施（MySQL、trade_cal、web console、live_positions）是允许的。
3. 任何一方的策略逻辑**不得导入或依赖**另一方的选股/评分/排序/调仓函数。
4. 新增策略必须明确归属到 sina 或 chenyiyun 体系，或作为独立的第三体系。

## 后果
- **正向**：避免信号污染；每条策略链的归因、回测和故障排查独立可复现。
- **负向**：部分通用逻辑可能出现两份实现；需要额外的 code review 防止耦合。
- **合规**：违反此规则的回测结果不得作为生产依据。
