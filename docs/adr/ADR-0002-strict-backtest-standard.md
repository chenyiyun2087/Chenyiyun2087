# ADR-0002: 可信回测的点时数据、T+1、成本与未来函数控制标准

## 状态
已接受（Accepted）

## 日期
2026-06-21

## 背景
项目存在大量回测变体：研究回测、年度回测、账户级可信回测、M2-M8 事件级回测。不同回测的数据切面、执行假设和审计要求不同。

## 决定
**可信回测**（Trusted Backtest）必须同时满足：

1. **点时数据**：信号日 T 只能使用 ≤ T 日收盘时已落库的数据。
2. **T+1 执行**：所有成交使用 T+1 开盘价，不得使用 T 日收盘价。
3. **成本模型**：单边至少 7.5bp 手续费 + 10bp 滑点。
4. **持仓约束**：Top5、最大持仓数、持有期必须与生产配置一致。
5. **公司行为**：分红、送股、配股、拆并股、退市必须在账本中正确反映。
6. **可复现性**：相同代码 commit + config SHA + data snapshot → 相同回测结果。
7. **未来函数审计**：回测不得引入信号日之后的数据。

**研究回测**可以放宽参数、因子和持仓约束，但**不得将结果直接作为生产收益结论**。

## 后果
- **正向**：生产决策有明确的回测可信度边界。
- **负向**：开发新策略时需要区分"研究结论"和"生产结论"两种口径。
- **合规**：生产候选导出、影子盘和实盘复盘必须使用可信回测口径。
