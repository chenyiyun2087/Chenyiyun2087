# 人工确认 Canary 运行手册

## 当前边界

- 账户总资金：1,000,000 元。
- Canary 新增资金上限：100,000 元（10%）。
- 只允许人工确认下单；仓库没有、也不得启用券商 API 自动报单。
- 当前配置 `live_canary.enabled=false`，严格账本未验证前不得改为 `true`。

## 每日准入

1. 运行策略治理审计，确认审计包状态与配置哈希。
2. 运行严格账本验证、影子盘验收和每日健康检查。
3. 仅在严格账本 VERIFIED、影子盘已连续运行至少 20 个真实交易日、健康度 GREEN、版本审批已记录时，人工允许新买单。
4. 人工复核交易权限、ST/停复牌、涨跌停、行业集中度、订单金额、总持仓上限和风险总闸，再于券商终端确认。
5. 将成交 CSV 经 `scripts/ops/import_manual_broker_fills.py` 导入，再对账并保存订单、成交、现金和持仓证据。

## 熔断与处置

- 5 日亏损达到 -8%：停止加仓并人工复核。
- 20 日回撤达到 -15%：切换防守口径。
- 峰值回撤达到 -25%：冻结新买单；达到 -30%：停止策略并复盘。
- 数据延迟、执行偏差、对账差异或公司行为异常：冻结相关买单，卖出仅按风险处置执行。

## 扩容

Canary 必须完成至少 60 个真实交易日和 30 个完整交易回合，且所有对账和执行质量门槛持续通过，才可按 10%→25%→50%→100% 的账户比例逐级人工审批。每一级至少运行 60 个交易日；任一硬门槛失败即回退并复盘。
