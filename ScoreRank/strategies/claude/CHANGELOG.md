# 更新日志

本文档记录项目的所有重要变更。

## [1.0.0] - 2024-02-14

### 新增功能
- ✨ 实现六因子评分体系 (Breakout, Trend, Volume, RS, Liquidity, Contraction)
- ✨ 实现入库/出库状态机管理
- ✨ 实现Trade/Watch分层输出
- ✨ 实现每日自动化复盘流程
- ✨ 支持横截面Rank标准化
- ✨ 支持权重归一化和综合评分
- ✨ 支持涨停/ST惩罚机制
- ✨ 完整的技术指标计算模块
- ✨ 灵活的买卖点信号生成
- ✨ 可配置的参数系统

### 模块说明
- **utils.py**: 工具函数和数据结构 (~400行)
- **indicators.py**: 技术指标和因子计算 (~500行)
- **signals.py**: 买卖点信号生成 (~300行)
- **inventory.py**: 库状态机管理 (~350行)
- **scoring.py**: 评分引擎 (~400行)
- **engine.py**: 主执行引擎 (~450行)
- **visualization.py**: 可视化模块 (~400行)

### 输出功能
- 📊 每日Trade候选列表 (CSV)
- 📊 每日Watch观察列表 (CSV)
- 📊 库存状态跟踪 (Excel, 含历史)
- 📊 摘要报告 (TXT)
- 📈 因子分布图
- 📈 因子相关性热力图
- 📈 评分vs收益散点图
- 📈 库存表现分析图

### 配置支持
- ⚙️ 因子权重可配置
- ⚙️ 分层阈值可配置(绝对值/分位数)
- ⚙️ 买卖点规则可配置
- ⚙️ 交易成本可配置
- ⚙️ 所有参数均可通过YAML文件调整

### 文档
- 📖 完整的README.md
- 📖 项目结构说明 (PROJECT_STRUCTURE.md)
- 📖 快速开始指南 (QUICKSTART.md)
- 📖 示例代码 (example.py)
- 📖 代码注释覆盖率 > 90%

### 技术特性
- 🚀 纯Python实现,无外部API依赖
- 🚀 模块化设计,易于扩展
- 🚀 支持模拟数据和真实数据
- 🚀 向量化计算,性能优化
- 🚀 完整的错误处理
- 🚀 日志记录功能

### 已知限制
- ⚠️ 暂不支持实时行情
- ⚠️ 暂不支持完整回测引擎
- ⚠️ 图表中文显示需要字体支持
- ⚠️ 部分指标计算需要至少120天数据

## 贡献指南

欢迎贡献! 请遵循以下步骤:

1. Fork 本项目
2. 创建特性分支 (`git checkout -b feature/AmazingFeature`)
3. 提交更改 (`git commit -m 'Add some AmazingFeature'`)
4. 推送到分支 (`git push origin feature/AmazingFeature`)
5. 开启 Pull Request

- 遵循 PEP 8
- 添加适当的注释和文档字符串
- 保持函数简短(< 50行)

- style: 代码格式
- refactor: 重构
- test: 测试
- chore: 构建/工具
